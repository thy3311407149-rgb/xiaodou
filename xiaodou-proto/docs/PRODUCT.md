## 1. 用户体验分析

### 目标用户
- **知识工作者 / 学生**：课堂、会议、阅读后需要把碎片信息沉淀为可检索知识
- **重度笔记用户**：录音、随手记、PDF/Word 同库管理，并希望 AI 辅助拆解与问答
- **复习与创作场景**：通过图谱关联与「问小豆」快速召回、重组知识点

### 核心需求（按优先级）
| 需求 | 说明 | 对应能力 |
|------|------|----------|
| 多源采集 | 录音 / 随心记 / 文件统一入库 | 知识库首页三入口 |
| 可检索沉淀 | 转写、摘要、标签后可搜 | 列表筛选 + 全局搜索 |
| AI 拆解文档 | PDF/Word 大纲、摘要、原文回跳 | 条目详情 · AI 拆解 |
| 对话式调用 | 基于库内语料问答 | 问小豆 |
| 关系可见 | 概念/来源/难点互联 | 小豆图谱 |
| 轻量陪伴 | IP「小豆」降低 AI 工具感 | 问候区 / FAB / 解析陪伴 |

### 核心交互逻辑
1. **采集为中心**：知识库默认落地；录音 → 转写预览 → 入库；随心记一键保存；文件加入后自动拆解。
2. **听写读一体**：列表条目进入详情；文档可看 AI 拆解、原文预览、相关知识高亮。
3. **问库不离库**：任意时刻可通过 Tab / FAB 进入问小豆，引用库内录音与文档。
4. **图谱是导航**：节点点击回跳条目或相关知识面板，不做重社交。
5. **搜索横切**：顶栏入口覆盖笔记 / 录音 / 文档要点。

## 5. 关键用户路径

**路径 A · 课堂采集**  
知识库 → 录音 → 结束转写 → 改稿入库 → 列表置顶

**路径 B · 文档拆解**  
解析文件 → 拆解中 → 详情看大纲 → 原文回跳 / 相关知识

**路径 C · 问答复用**  
问小豆 → 建议问题 / 自拟 → 回答带库内引用 → 跳转条目

**路径 D · 图谱导航**  
小豆图谱 → 点节点 → 相关知识 / 条目详情
