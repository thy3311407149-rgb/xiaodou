# Backend

当前后端说明以仓库根目录的 `README.md` 和 `docs/development.md` 为准。下面的 Phase 5.1 段落只保留为早期骨架记录。

Phase 5.1 only contains the backend project skeleton and `GET /health`.
Business APIs, SQLite tables, PDF processing, tasks, Agent, and LLM integration are intentionally not implemented yet.

## Development

```powershell
npm install
npm run dev
```

The default health endpoint is `http://127.0.0.1:3000/health`.
