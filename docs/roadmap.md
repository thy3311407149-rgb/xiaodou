# 路线图

范围按当前代码划分。界面演示里出现、但没有持久化实现的流程，列在规划中。

## 已实现

- PDF 上传、类型和大小校验、本地存储
- 进程内任务队列、状态查询和重启恢复
- 页面文本抽取、清洗和分块
- 文本模型摘要、知识点和页码引用
- 知识库列表回读、摘要、解析正文和原始 PDF
- 关键词检索接口，以及基于检索结果的问答接口
- 请求 ID、统一错误体、CORS 精确来源
- 后端 Vitest、前端 Vitest 和 oxlint

## 开发中

没有正在实现的录音或随心记分支。界面上的录音和笔记仍是本地演示。

## 规划中

- 录音采集、原始音频保留、语音转写
- 转写完成后复用现有摘要链路
- 随心记的创建、编辑、摘要和知识点
- PDF、录音、随心记共用的知识库内容类型
- 把「问小豆」页面接到已有的检索和问答接口
- 知识关联或图谱
- 公网访问前的身份或设备访问控制

这些规划会改变目前只允许 PDF 的文件类型和只允许 `PROCESS_PDF` 的任务类型。在单独确认 Schema 和接口之前，不直接修改现有 PDF 流程。

## 已知限制

- 执行器是单进程的，长任务会挡住队列里的下一份 PDF。
- 重新打开页面后，未完成的 PDF 不会自动继续轮询。
- 列表总数不是全库计数。
- 软删除不级联清理摘要和分块。
- 初始迁移不能修改已经创建的表。
- 摘要长度没有服务端硬限制。长文会被抽样后再送给模型。
